__call__(repeat_p=gate_run_once, max_cycles=None, dp_err_p=None, other_err_p=None, **args)¶

After initialization (dp.reinit, add arguments), runs a cogent loop…

  1. Cache sensor(s) perception to IO

  2. Run the decision process

  3. Check the gating predicate (reinitialize the decision process if not done)

until the supplied gating predicate returns False

Parameters:

  • repeat_p (cognition.util.functypes.Predicate[Cogent[DP]]) – gating predicate (assuming no errors)

  • max_cycles (int | None) – maximum dp cycles to run per loop; None indicates no limit

  • dp_err_p (cognition.util.functypes.BiPredicate[cognition.decision.core.DecisionProcessErrorMessage, Self] | None) – gating predicate to continue if a known error type occurs (or raise if None) (see cognition.decision.core.DecisionProcessExecutionError)

  • other_err_p (cognition.util.functypes.BiPredicate[Exception, Self] | None) – gating predicate to continue if an unknown error type occurs (or raise if None)

  • args (Any) – IO args to add (see cognition.decision.dp.args_added())

Returns:

this cogent (for chaining)
